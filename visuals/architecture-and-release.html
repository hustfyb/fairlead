ARCHITECTURE · RELEASE

三个信任边界，五个可回滚的版本

公网 Nginx 只做入口治理，Host 只做路由决策，Agent 只做字节搬运。没有一层替上一层理解语义。

01

分层与信任边界

监听地址即权限范围
公网唯一暴露面 · 终止 TLS · 不管路由

Nginx 公共监听

通配符证书；覆盖客户端伪造的 X-Forwarded-*；限流、请求体上限、访问日志。

Connection: close 打到上游，Host 原样透传。

客户端

只认域名，不感知隧道。标准端口或部署者自选的非标准端口，同端口承载全部域名。

a1.relay.example.com:8080 · a2.relay.example.com:8080

回环 · 明文 HTTP/1.1 · 一连接一请求 · 上游不 keepalive · 只信任 127.0.0.1 来源
回环Host Edge :9000 · 只读头，读完整路由决策再放手

请求头嗅探

只读请求行与头（上限 16KB）；归一化 Host：去端口、小写、后缀校验。之后原样 splice，不做 HTTP 语义代理。

RouteTable 快照

ArcSwap<HashMap> 整表替换，读侧无锁。数据面永不查 SQLite。

变更 2s 内生效，零 reload。

TunnelPool

每 Agent 2–4 条物理隧道，按流轮转。一条大下载不拖死同 Agent 的其他 Route。

Admin :9001

独立监听、独立中间件，绝不复用 Edge 的鉴权链。/metrics 只在这里，不外露。

日志批写

有界 channel + 250ms 批量落库；满了丢并计数，不反压数据面。

SQLite 单写者

WAL + 独立 actor 串行写，避免 BUSY；迁移只前进，启动时执行。

控制连接 · TLS 1.3 :9443 · 持久复用 · 每请求一条逻辑流
隧道传输与协议解耦：换 QUIC 不改路由逻辑

控制流

Hello / 路由声明 / 心跳 / 期望策略下发。长度前缀二进制帧，带协议版本，超长即拒。

数据流

Host 开流后先写 route_id + 已读请求头字节，然后两侧纯字节管道对接。

1 字节状态前导

Agent 先回 00 成功 / 01 拒绝 / 02 超时。没有它，502 和 504 只能靠猜。

Agent 主动出站 · 策略在 Host，执行在 Agent · 重连 1s→30s 带抖动
内网没有公网 IP，没有入站端口

Agent A

不解析 HTTP，只连本地目标并双向复制；半关闭、RST、异常断开都向两端传播。

目标白名单与私网范围在本地校验，Host 下发的策略不可被 Agent 放宽。

Agent B

凭据落盘 0600，首次注册换长期凭据；单机一台，多 Agent 各自持有独立凭据。

断线后 Route 标 offline，重连自动恢复，但不覆盖管理员停用。

02

一次请求的四段

状态码由「谁失败」决定
01 / 入口

Nginx 收口

终止 TLS，丢弃伪造转发头，写入真实客户端 IP。

Host $http_host
02 / 路由

Host 决策

读头不读体，查只读快照；未命中直接 404，不占隧道。

:8080 → 归一化 Host
03 / 隧道

开流握手

轮转选隧道 → 开流 → 写请求头 → 等状态字节，等待有独立超时。

00 ok · 01 拒 · 02 超时
04 / 回传

字节管道

双向 copy，FIN 传播半关闭；101 之后完全透明，WebSocket 白送。

request_id 贯通两层日志
404无此路由或 Host 不合法
503路由在，Agent 离线
502连本地目标被拒
504连本地目标超时
