单台公网服务器 控制面 + 数据面
Edge / 反向代理 按 Host / Path / SNI 路由；处理 HTTPS、WebSocket 和请求日志。
控制台 + API 管理 Tunnel、Agent、路由、域名和证书；下发期望配置。
证书管理 通过 ACME DNS-01 自动签发和续期自定义域名证书。
配置数据库 保存路由、Agent 状态、域名记录和加密后的 Cloudflare Token。
TLS 终止 Host 路由 配置下发 单点故障
